# 인력 배치 기록

건설 현장별로 "어떤 인원이 어느 날 어느 현장에 나갔는지" 기록하는 사내용 웹앱입니다.

- **데이터는 이 프로그램을 돌리는 PC/서버의 `data/manpower.db` 파일 하나에만 저장됩니다.** 외부 클라우드·외부 서비스로 나가지 않습니다.
- 로그인한 사람만 접근할 수 있고, 권한은 3단계입니다.
  - **관리자**: 전부 + 사용자 관리
  - **입력**: 배치 입력/삭제, 인원·현장 관리
  - **열람**: 조회, 집계, CSV 내려받기만 가능
- 수정/삭제 이력은 남기지 않습니다. 입력자와 입력 시각만 기록합니다.
- 외부 패키지 설치가 필요 없습니다. (Node.js 22.13 이상만 필요)

## 실행

```bash
npm start            # http://서버주소:3000
```

처음 실행하면 관리자 계정(`admin`)과 임시 비밀번호가 터미널에 한 번 출력됩니다. 로그인 후 `내 계정`에서 바로 바꾸세요.
비밀번호를 직접 정하려면 `ADMIN_PASSWORD=... npm start` (최초 실행 시에만 적용).

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 포트 |
| `HOST` | 0.0.0.0 | `127.0.0.1`로 두면 그 PC에서만 접속 |
| `DATA_DIR` | ./data | DB 파일 위치 |
| `SECURE_COOKIE` | (끔) | HTTPS 뒤에서 운영하면 `1` |

## 운영 시 꼭 확인할 것

1. **백업**: `data/manpower.db`(와 `-wal`, `-shm` 파일이 있으면 같이)를 주기적으로 다른 곳에 복사하세요. 서버를 멈추고 복사하는 게 가장 안전합니다.
2. **HTTPS**: 사내망 안에서만 쓰면 HTTP도 가능하지만, 인터넷에 노출한다면 반드시 HTTPS 리버스 프록시(Caddy, nginx 등) 뒤에 두고 `SECURE_COOKIE=1`을 켜세요.
3. **PC 보안**: DB 파일에 직원 이름·연락처가 들어 있으니 서버 PC 접근 권한과 디스크 암호화를 관리하세요.
4. 연락처 같은 민감 항목이 꼭 필요하지 않다면 비워두는 게 안전합니다. (주민번호 등은 입력받지 않도록 만들었습니다.)

윈도우 PC에서 폰으로 접속하는 설치 방법은 [docs/windows-setup.md](docs/windows-setup.md)를 보세요. (`start.bat`, `backup.bat` 제공)
